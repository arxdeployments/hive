## 3. API CLIENT (src/api/client.js)
- axios instance; `baseURL = process.env.REACT_APP_BACKEND_URL || ''` (falls back to same-origin relative paths); default header `Content-Type: application/json`.
- **Request interceptor**: attaches `Authorization: Bearer <localStorage.access_token>` if present.
- **Response interceptor**: on 401 (and not `_retry`): single-flight refresh with `isRefreshing` flag + `failedQueue` of pending promises; refresh via bare `axios.post(${API_BASE}/api/auth/refresh, {refresh_token})`; stores new `access_token` (+`refresh_token` if returned), replays queued+original requests with new token; on refresh failure clears `access_token`/`refresh_token`/`user` and hard-redirects `window.location.href='/login'`.
- Token storage: localStorage keys `access_token`, `refresh_token`, `user` (JSON). WS auth passes token as query param.
- There are NO wrapper API methods — pages call `client.get/post/put/delete` directly. Complete endpoint inventory (all paths relative to base):
  - Auth: `POST /api/auth/login {email,password}` → `{access_token, refresh_token?, user}`; `GET /api/auth/me`; `POST /api/auth/logout`; `POST /api/auth/refresh {refresh_token}`.
  - Profile/users: `PUT /api/users/profile {display_name|about|avatar_url}`; `GET /api/users/contacts?search`.
  - Conversations: `GET /api/conversations?search&filter` → `{data:[...]}`; `POST /api/conversations/direct {participant_id}`; `POST /api/conversations/group {name,description,member_ids}`; `PUT /api/conversations/{id}/read`; `GET /api/conversations/{id}/messages?limit=50[&before=<msgId>]` → `{messages, has_more}`; `POST /api/conversations/{id}/messages {content,type,temp_id}`; `POST /api/conversations/{id}/messages/search?q=`; `GET /api/conversations/{id}/media?type=image&limit=9`; `PUT /api/conversations/{id}/group {name|description|admin_only_messages}`; `POST /api/conversations/{id}/members {user_ids}`; `DELETE /api/conversations/{id}/members/{memberId}`; `PUT /api/conversations/{id}/members/{memberId}/role {role}`; `POST /api/conversations/{id}/leave`.
  - Messages: `GET /api/conversations/messages/{id}/info`; `POST /api/conversations/messages/{id}/react {emoji}`; `DELETE /api/conversations/messages/{id}?for_everyone=bool`; `POST /api/conversations/messages/forward {message_id, conversation_ids, contact_ids}`.
  - Search: `GET /api/search?q&types=conversations,contacts,messages`.
  - Upload (raw fetch, NOT axios): `POST ${backendUrl}/api/upload` multipart w/ Bearer header → `{file_url, file_type, filename, thumbnail_url?}` (used by MessageComposer + ProfileDrawer).
  - Calls: `GET /api/calls/history?filter&limit`; `GET /api/calls/missed-count`; `POST /api/calls/create-link {call_type}`; `GET /api/calls/ice-servers`.
  - Superadmin: `GET /api/admin/stats`; `GET/POST /api/admin/organizations` (`?page&limit&search&sort&order`); `PUT/DELETE /api/admin/organizations/{id}`; `GET /api/admin/organizations/all`; `GET /api/admin/organizations/{id}/users`; `GET /api/admin/validate/org-name?name&exclude_id`; `GET/POST /api/admin/departments` (`?org_id&page&limit&search`); `PUT/DELETE /api/admin/departments/{id}`; `GET/POST /api/admin/users` (`?page&limit&search&org_id&dept_id&status`); `PUT /api/admin/users/{id}`; `POST /api/admin/users/{id}/reset-password`; `POST /api/admin/users/bulk-action`; `GET /api/admin/validate/user-email?email`; `GET/POST /api/admin/cross-org-groups` (`?page&limit&search&status`); `POST /api/admin/cross-org-groups/{id}/archive`; `DELETE /api/admin/cross-org-groups/{id}`.
  - Org-admin: `GET /api/org-admin/stats`; `GET /api/org-admin/activity`; `GET/POST/PUT/DELETE /api/org-admin/departments[/{id}]`; `GET/POST /api/org-admin/users` (`?page&limit&search&dept_id`); `PUT /api/org-admin/users/{id}`; `POST /api/org-admin/users/{id}/reset-password`; `GET/PUT /api/org-admin/settings`.

**WebSocket (src/services/websocket.js)** — singleton class `RxHiveWebSocket`. URL: derived from `REACT_APP_BACKEND_URL || window.location.origin`, `ws(s)://host/api/ws?token=<jwt>`. Features: message queue while disconnected, 30s ping heartbeat w/ 10s pong timeout, exponential backoff reconnect (2^n s, cap 30s), close code 4001 = auth failure → clear tokens + redirect /login, reconnect re-fetches `/api/conversations`. Outbound helpers: `sendMessage(convId, content, tempId, replyTo)` (`type:'message'`, msg_type:'text'), `sendTypingStart/Stop`, `sendReadReceipt(convId, lastReadMessageId)`; raw `send()` used for all call signaling (`call:initiate`, `call:group_initiate`, `call:accept`, `call:join`, `call:decline`, `call:cancel`, `call:end`, `call:toggle_media`, `webrtc:offer/answer/ice-candidate`). Inbound message types routed to stores: `connected`, `pong`, `message_ack` (replace optimistic), `new_message` (add + bump + unread + Web Audio beep + browser Notification), `message_status`, `messages_read` (batch mark read up to id), `typing` (4s auto-clear), `presence`, `conversation_created/updated`, `member_added/removed`, `removed_from_conversation`, `role_changed`, `member_left`, `reaction_update`, `message_deleted`, and ~20 `call:*`/`webrtc:*` types (incoming, ringing_started, group_started, group_participants, full, group_already_active, accepted, declined, ended, cancelled, busy, unavailable, missed, participant_joined/left, media_toggle, group_active, group_ended, offer/answer/ice-candidate w/ group-vs-1:1 dispatch), `error`.

## 8. CRA→VITE PORT HAZARDS (behavior-preserving checklist)
1. **CommonJS `require()` in ESM app code** — will crash under Vite: `services/websocket.js` (many: callStore, meshCallManager, webrtcManager, sonner), `components/chat/ChatPanel.js` (websocket + callStore inside onClick handlers), `services/webrtcManager.js` (callStore in stats loop). These were likely used to dodge circular imports (websocket↔stores↔managers); convert to static imports (no true cycle at module-init time for most) or `await import()`.
2. **`process.env.REACT_APP_BACKEND_URL`** in 13 files → `import.meta.env.VITE_BACKEND_URL` (or define shim). Several are module-level consts — evaluated at import time.
3. **JSX in `.js` files** everywhere → either rename to `.jsx` or configure esbuild `loader: {'.js':'jsx'}` for dev + build plugin.
4. **`@` alias** (jsconfig + craco webpack alias) used only in `src/index.js` (`@/index.css`, `@/App`) and throughout components/ui — replicate in vite.config resolve.alias.
5. **index.html** moves to root with `<script type="module" src="/src/index.js">`; decide whether to keep emergent.sh script + PostHog snippet (recommend dropping; they're Emergent-platform artifacts). Title currently "Emergent | Fullstack App" (Chat.js overwrites document.title at runtime to "RxHive").
6. **craco-only features to drop**: `@emergentbase/visual-edits` wrapper, health-check plugin (`frontend/plugins/health-check/`), eslint-in-webpack config.
7. **Dev proxy**: CRA had none configured — app relies on REACT_APP_BACKEND_URL or same-origin; keep same contract (or add Vite server.proxy for `/api` + `/api/ws` websocket).
